## 시험판 v799 — 첫 로딩 줄이기
- 잰 것(느린 휴대폰 흉내 · CPU 4배 느리게): 켠 뒤 캐릭터 선택 화면까지 10.6초 → 4.5초, 두 번째 실행부터 약 3초 / 「모험 시작」 뒤 게임 화면까지 4.5초 → 3.7초
- 원인 ①: 캐릭터 선택 화면이 완전히 덮고 있어 보이지도 않는 배경 마을(부여)을 켤 때마다 만들고 매 프레임 그리고 있었음 → 실제로 보일 때만 만든다
- 원인 ②: 켜자마자 그림 310장(9MB)을 받았음 → 30KB 넘는 그림은 시작 뒤에 받는다(전에는 100KB 넘는 것만). 그리려는 순간 아직이면 그 자리에서 바로 받는 기존 장치 그대로. 첫 화면 전에 받는 그림 약 9MB → 3MB
- 원인 ③: 게임 코드 6MB가 페이지 안에 들어 있어 실행할 때마다 처음부터 다시 풀었음 → 옆 파일(game.<지문>.js)로 뺌. 브라우저가 풀어 둔 것을 기억해 두 번째 실행부터 빨라진다. 한 파일판(game.html)은 그대로
- 새로: 준비되는 동안 「불러오는 중」 가림막(전에는 반쯤 그려진 조작 화면이 보였음). 30초가 지나면 저절로 사라짐
- 서비스 워커(pwa/sw.js): game.<지문>.js 도 한 번 받으면 그대로 쓰고, 새것을 받으면 옛것을 지움 — 본편에 올릴 때 같이 적용됨
- 확인: 오류 점검 · 저장 호환 · 전투 시험 통과 / 모바일 틀 가로 57화면 오류 0 / 느린 통신(10Mbps) 흉내에서 첫 게임 화면 그림 빠짐 없음
- 확인 못 한 것: 실제 휴대폰에서의 시간(위 숫자는 PC에서 흉내 낸 값) · 아이폰 사파리에서 두 번째 실행 효과
- 본편에 올릴 때: index.html 과 함께 game.<지문>.js 를 복사하고 옛 game.*.js 는 지운다 (sw.js 도 새것으로)
