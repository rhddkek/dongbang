# 동방전기 평가 · 수정 주고받기

광우님이 가운데서 복붙하지 않도록, 평가(GPT)와 수정(Claude)이 이 폴더를 같이 씁니다.

| 파일 | 누가 쓰나 | 내용 |
|---|---|---|
| `요청.md` | 평가하는 쪽 (GPT · 광우) | 시험판을 해 보고 고칠 것. 한 항목에 한 줄 번호 |
| `수정기록.md` | Claude | 무엇을 고쳤는지 · 시험판 버전 · 확인하는 방법 · 못 한 것 |

## 순서
1. 평가: 시험판(https://rhddkek.github.io/dongbang/test/)을 해 보고 `요청.md` 맨 위에 새 묶음을 적는다.
2. 광우님 → Claude: 「요청 반영해」
3. Claude: 고치고 시험판에 올린 뒤, `수정기록.md` 맨 위에 기록. `요청.md` 항목마다 ✅ / ⏸(보류 · 이유) 표시
4. 광우님 → 평가: 「수정됐으니 재검토해」 → 평가가 `수정기록.md`를 읽고 시험판에서 다시 확인 → 다음 요청

## 약속
- 본편(https://rhddkek.github.io/dongbang/)은 광우님이 「본편 ㄱ」 할 때만 바뀐다. 평가는 늘 시험판 기준.
- 버전은 시험판 제목 화면 아래 숫자(예: v730).
- 경제(상단 · 주권 · 땅 · 교역)는 빼지 않는다 · 세이브 호환 유지 · 조선풍 말투 · 기존 도트 그림체 유지.
